The Fluent theme's Button — use it for every command surface; `variant="accent"` is the single primary action per view.

```jsx
<Button variant="accent">Save</Button>
<Button icon={<PathIcon data={ICONS.Refresh} size={16} />}>Refresh</Button>
```

Variants: `standard` (translucent base-low fill — the default), `accent`, `outline`, `transparent`. Hover lightens, press darkens; nothing scales or lifts.
